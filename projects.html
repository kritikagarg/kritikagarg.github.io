colibri: keeping a Mixture-of-Experts engine from stalling

Merged upstream. Skips about 22% of late expert loads for a 2.9% perplexity cost, so generation never stalls.

View merged pull request
Problem
colibri runs large Mixture-of-Experts models on consumer hardware by streaming expert weights from disk. When an expert loads late, decoding stalls.
Contribution
An opt-in policy, DEGRADE_ZERO, that skips low-weight experts on a load miss so generation continues. It is decode-only to protect the KV cache, off by default, token-exact when disabled, and reports per-layer telemetry. The default setting zeroes about 22% of expert slots for a 2.9% perplexity cost.
Quality
Refined through two review rounds and merged with a 20-check test suite and tuning documentation.
2026 · Kubernetes, vLLM, LMCache, Ray

Serving and accelerating an 8B LLM on Amazon EKS

21× faster time to first token with KV-cache offloading, and a measured saturation point of about 9 requests per second per GPU.

Setup
Ministral-3-8B served with vLLM on one NVIDIA L40S GPU, monitored with Prometheus, Grafana and DCGM, and scaled out with Ray Serve. A tool-calling agent built with the Strands Agents SDK runs on the same model.
Findings
  • Offloading the KV cache with LMCache cut time to first token 21-fold for prompts sharing a long prefix.
  • One GPU saturates near 9 requests per second; beyond that, median latency rises from 196 ms to 23 s.
